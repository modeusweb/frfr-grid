# FrFr — CSS Grid Генератор

Рисуйте сетку мышкой — забирайте готовый CSS и HTML. Никакой теории: выделили клетки — код уже в панели справа.

## Демо

👉 **[frfr-grid.vercel.app](https://frfr-grid.vercel.app/)** — открывайте и тяните мышкой, всё работает прямо в браузере.

## Что умеет

- 🖱️ **Рисование мышкой** — выделение, растягивание за ручку, перетаскивание областей; сетка до 12 × 12
- 🧩 **Шаблоны** — 11 готовых лейаутов с живыми превью: holy grail, bento-сетка, мозаика, «крест»…
- 📐 **Тонкая настройка** — размеры треков (`fr`, `px`, `%`, `rem`, `auto`…), раздельные gap-ы, пресеты
- ⚡ **Живой код** — CSS и HTML генерируются на лету, копирование в один клик
- 🔗 **Поделиться** — вся сетка упаковывается в ссылку `?config=...`
- ↩️ **Undo / Redo** — 100 шагов истории и горячие клавиши
- 💾 **Автосохранение** — сетка переживает перезагрузку (localStorage)
- 🌙 **Тёмная тема** — включается сама, как в системе
- ♿ **Доступность** — aria-атрибуты, фокус-состояния, `prefers-reduced-motion`

Сломать сетку не выйдет: перекрытия и кривые имена областей подсвечиваются сразу.

## Технологии

| Слой | Инструмент |
|---|---|
| Framework | Next.js 16 (App Router, Turbopack) |
| UI | React 19, TypeScript (strict) |
| Стили | Tailwind CSS 4 |
| Иконки | Heroicons |

Остальное написано руками: drag, валидация, сериализация и подсветка кода — без рантайм-зависимостей.

## Запуск

```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # production-сборка
npm start      # production-сервер
```

## Структура

```
app/                        # страница, метаданные, стили, PWA-манифест
components/grid-generator/  # редактор сетки, настройки, панель кода, модалки
hooks/                      # история, выделение, горячие клавиши, localStorage
lib/                        # генераторы CSS/HTML, валидация, сериализация, шаблоны
types/                      # модель данных сетки
```

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl/Cmd + Z` | Отменить |
| `Ctrl/Cmd + Shift + Z` / `Ctrl/Cmd + Y` | Повторить |
| `↑ ↓ ← →` | Сдвинуть выбранную область |
| `Delete` | Удалить выбранную область |
| `Escape` | Снять выделение |
| `?` | Справка |
